## 2. Unified Thesis Build（`scripts/thesis_build.py`，commit `99cb402` + 接线修复 `49d89b7`）

- **Build Contract** `.aeromech/build-contract.yaml`（指令 §五/§七）：project/content（title、author、abstract、keywords、chapters、references、appendices、ack）/research/school_format/figures/tables/qa/output。缺失语义：必需缺→ERROR 列缺项；可选缺→NOT_APPLICABLE 披露清单；**无任何静默补假数据**。
- **统一组装**（§六）：双模式自动选择（复用 `select_docx_mode`）——TEMPLATE_FIDELITY：open_master→剪样例区→封面填值→母版原语追加摘要/目录域/正文/文献/附录/致谢（前置罗马+正文decimal 防重启节规则继承 v1.1.0 纪律）；FORMAT_RECONSTRUCTION：docx_engine 重建。**项目不再手写 builder**（t3~t7 各写一个 build_docx_*.py 的历史由此终结）。
- **Artifact Manifest**（§八）：`artifacts/build/artifact-manifest.yaml`——build_id/每产物 {artifact,path,sha256,content_identity,producer,timestamp,status} + meta.steps（每步 rc/状态）。与 Phase 3 checkpoint 同构（sha256 一致性=resume 依据）；`check_manifest` 输出 missing/changed。
- **Pipeline runner**（§六/§十四）：docx→toc→repaginate→pdf→qa→finalize 固定顺序子进程调既有脚本（update_toc/repaginate_tables/export_pdf/finalize_metadata/12 QA），每步 {step,rc,status,output_tail}；失败时输出 **{failed_stage, error_code, reason, suggested_action}** 且下游步骤记 SKIPPED_WITH_REASON——不假装成功。
- **可重复性**（§十八）：`content_identity`（docx 排除 docProps/*.rels 的逐条目归并哈希）与容器 sha256 **分离**——同输入两次 build content_identity 严格一致（测试锁），元数据时间戳差异不误报内容漂移；PDF 侧 `pdf_text_identity`（逐页文本+图像字节）。
- **图嵌入接线**（自查抓到的缺口）：build 命中 parse_md 占位行（display 键归一 "图1-1"→"1-1"）且图文件在场→生命周期补记 EMBEDDED；未命中的图不伪造记录（测试锁）。

## 3. Delivery Gate Aggregator（`scripts/delivery_gate.py`，commit `a538b2a`）

- **统一消费**（§九/§十二 格式链已真正接入）：10 个格式 QA md 报告（tf/cover/cover_align/cover_fill/color/page/figure_table/graph/table/content_purity，解析 `- CODE: ST | 证据` 行）+ pipeline 步骤记录（pdf_qa/visual/toc/repaginate/pdf/finalize）+ Document/PDF（存在性+manifest 一致性）+ Figure 生命周期 + 研究侧（**复用 stage_routing.delivery_gate_status，不重算 RQG/loop**）+ 人工双队列。
- **五态终局**（§十）：RANK 聚合 ERROR>BLOCK(Critical/High FAIL)>PASS_WITH_HUMAN_REVIEW>PASS_WITH_WARNINGS>PASS；无模板=tf_qa 自身输出 N/A（不伪造 PASS 也不 BLOCK）；全 N/A/无决定性证据=BLOCK（未执行≠通过）；**note 明记 Overall Score 不参与放行**（GATE-07 测试锁：格式全过+研究 Critical 未解→BLOCK）。
- **每项 Gate 带证据**（§十一）：{gate_id,domain,status,severity,evidence(项目根相对路径,不泄露绝对路径),reason,remediation}；`--write` 落 `gate-summary.json + gate-report.md`。
- **Orchestrator 接入**：`gate` 子命令与 `FINALIZE` 改用全聚合器（写 gate-summary）；旧项目 gate 不误伤也不误判：t7.0（已裁决+loop PASS）→**PASS**；t6.0（有未裁决队列）→**BLOCK+NHR** 如实（§十三）。

## 7. 已知限制（如实记录）

1. **格式链真实 QA 运行属 pipeline qa 步骤，测试夹具只合成报告**：完整"契约→build→toc→repaginate→pdf→QA→gate"真实跑通将在 test-8.0（Phase 6）做实战验证；本阶段以 t30~t70 逐脚本重跑证明链路脚本本身无回归。
2. LocalProvider 的 validate 依赖 figkit layout JSON（matplotlib 路线）；mermaid 渲染图该关由 PDF 级 GQ/FIG 检查在 VERIFIED 阶段兜底（记录中写明，不伪造几何通过）。
3. content_identity 排除 docProps 与 .rels：若两版文档**仅关系文件变化**（极少见，如图片 rId 重排）内容哈希相同——判定为内容等价属有意设计（指令 §十八"结构一致、内容一致"语义）；容器哈希差异单独披露。
4. Gate 的格式链证据来自 `artifacts/qa` 下 md 报告的解析；若项目把 QA 输出到别处需在契约 `qa.out` 声明（否则按缺证据处理，不会误 PASS）。
