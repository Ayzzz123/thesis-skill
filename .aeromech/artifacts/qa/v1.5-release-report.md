【Known Limitations】（诚实清单）
1. test-7.0 的"人工裁决/复核"由维护 Agent 按规程代演（reviewer 字段如实记录为复核人姓名）；
   真实交付中必须由人类完成（research-human-review.md §5 红线不变）。
2. diagnosis_id 稳定性依赖 payload 内容确定；若未来 payload 引入时间戳类字段需同步扩展 ID 策略。
3. recompute 白名单仅接受项目内 `.py` 脚本；其他解释器/编译型重算工具不支持（安全优先的取舍，已文档化）。
4. 旧交付脚本退出码未全面统一（pdf_qa 内容码 0/1/2 + 环境 3；export/update_toc 仅 0/1）——
   与 v1.4.1 标准并存的异构状态，改动会触碰 STABLE_MODULES，留待 v1.6 专项（技术债）。
5. visual_regression B 类豁免仍含 EXEMPT={0,3}+6 章检测硬编码（v1.5 未触碰稳定模块）。
6. Citation 评分粒度为"RQG-12 派生诊断扣分"，非逐引用强度审计（引用强度仍由 citation agent 人工规程负责）。
7. test-1.0/2.0 的 pdf_qa 历史 High（页码带）维持"既有差异非回归"定性，未 retro-fix。
8. 仓库无 requirements 清单（pymupdf/python-docx/pywin32/matplotlib 隐式依赖）；Windows+Word COM 环境依赖。
9. test-7.0 无学校模板——v1.5 能力在 TEMPLATE_FIDELITY 项目上的端到端只经 t30~t60 回归覆盖，
   未做"有模板 + intelligence 闭环"的联合冷启动（v1.6 候选 test-8.0）。

**v1.5.0 = PASS**
