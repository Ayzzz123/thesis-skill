# v1.6.5 — ACADEMIC_VISUAL_QUALITY_FIRST 视觉设计系统（V1.6.5_VISUAL_DESIGN_SYSTEM）

定位：一篇论文的所有图，像出自**同一套专业设计系统**。风格关键词
minimal / natural / restrained / clean / premium / academic / technical / professional。
禁止方向（任务 §十五）：渐变堆砌、重阴影、彩虹配色、无意义装饰、过细难读字体、
为好看牺牲数据可读、为 PASS 改期望、单例特判、单论文硬编码、单一总分掩盖 Critical。

> 重要原则：下列色值/字号是**候选基线**，v1.6.5 实现时必须(a)在白底渲染样图 +
> (b)灰度退化样图 + (c)黑白打印模拟 三种实测下确认，再固化为 `figure_style.py` 常量；
> 未经验证的色值不得写死。这是"颜色值必须通过实际视觉测试确定"的落地约束。

---

## A. Color System（有限全局调色板 + 语义映射）

**设计目标**：低饱和、自然、克制、高级、白底友好、高对比可读、黑白打印可退化、
不靠彩虹区分类别、不为区分而滥加颜色。

**候选基线（待实测固化）——一套冷中性学术蓝灰 + 单一强调 + 语义状态色：**

| 角色 | 语义 | 候选 HEX | 说明 |
|---|---|---|---|
| Primary | 主结构/顶事件/主干 | `#2E5A7D` | 沉稳蓝，非纯蓝；描边/主块 |
| Secondary | 次结构/中间事件 | `#5B7C99` | Primary 的降饱和派生 |
| Fill | 常规节点底 | `#EEF3F7` | 近白冷灰蓝底，低饱和 |
| Accent | 强调结果/关键割集 | `#C26B3E` | 克制赭橙，**全图最多 1 处语义强调** |
| Risk | 故障/风险（语义） | `#A94438` | 暗砖红，仅用于"风险/故障"语义 |
| Neutral | 正常/背景/次要 | `#9AA5AD` | 中灰蓝 |
| Text | 正文/标签 | `#1F2933` | 近黑（非纯黑，更耐看） |
| Grid | 网格/辅助线 | `#D8DEE3` | 极浅，不抢信息 |
| Line | 连线/箭头 | `#3A4A57` | 深冷灰，非纯黑 |
| Bg | 画布底 | `#FFFFFF` | 论文白底 |

**硬规则（可被 VIS-QA 度量）**：
1. **同语义同色**：同一论文内，"故障/风险"永远 `Risk`，"主结构"永远 `Primary`——
   由 `figure_style.py` 的 `SEMANTIC` 字典单一来源供给，禁止各图脚本自带 HEX（消灭 D3）。
2. **色相预算**：单图**填充类**色相 ≤ 3（Primary/Secondary/Fill 视为同族）；强调色每图 ≤1 语义用途。
3. **黑白退化**：任意两相邻填充色在灰度下的相对亮度差 ≥ 0.12（WCAG-like 灰度可辨）；
   线条/节点必须**同时**具备非颜色冗余编码（线型/形状/标签），使灰度打印仍可辨
   （AND/OR 门靠形状不靠颜色）。
4. **对比度**：文字对其底 ≥ 4.5:1（正文级）、对大块底 ≥ 3:1（大号标签）——按 WCAG 相对亮度公式计算，机器可判。
5. **禁彩虹**：不得出现红黄绿蓝紫橙同图并存；分类优先"同色系明度阶 + 标签"而非"多色相"。

## B. Typography System（统一字阶，中英数混排稳定）

- 字体族：**中文黑体族（SimHei/思源黑体）用于节点/标题，正文数字与西文用衬线或无衬线统一**——
  与论文正文（宋体/Times）区分但内部一致；fallback 链固定，禁止"字体裸奔"（消灭 D4）。
- 字阶（图内 pt，生成时字号；有效字号=×缩放后仍须达标）：
  - 图内主标题/顶事件：12–13
  - 节点/轴标签：11
  - 刻度/图例：10
  - 注释/note：9.5（**绝对底线 9**，对齐 SKILL 18.3）
- 中英数混排：同一标签内中文用 CJK 族、数字/单位/西文用配套拉丁族，字重一致；
  上下标（R(t)、E_max）、单位（MPa、飞行小时）、技术串（DOI、GB/T 7714、CCAR-145）
  必须**不换行断裂、不被裁、字号不低于底线**——列为 VIS-03 必测样例集。
- 一论文一图一字体规则：`figure_style.py` 提供 `FONT` 常量，所有 provider 取用。

## C. Spacing System（间距/留白/密度）

- 最小节点间距 ≥ 0.35cm（现 0.2 偏挤，收紧）；同层等距容差 ≤ 0.05cm。
- 文字安全区：文本 bbox 距框边 ≥ 0.08cm；距任何连线 ≥ 0.06cm。
- 图例安全区 / 标注安全区：不得与数据区、题注重叠，边距 ≥ 0.15cm。
- 页边距（图内绘制留白）：四周 ≥ 0.4cm，视觉重心不在几何中心而在光学中心（略偏上）。
- **最大信息密度**：单图节点 ≤ 12（超出→建议拆图/分层），文字块 ≤ 画布 55%（ink 面积比），
  拥挤度自动检测（见 VIS-02）。

## D. Geometry System（层级/对齐/平衡/阅读方向）

- 层级：顶→中→底三层垂直对齐；同层节点等宽等高基线；父子连线垂直主导（自上而下阅读）。
- 对齐：所有框左/中/右对齐到统一栅格；标签水平居中于节点。
- 平衡：分支左右子树节点数差 ≤ 1（故障树尤其，见 §八）；避免"一边倒"。
- 视觉重心与留白：非对称内容用留白平衡；不允许整图偏挤一角。

## E. Line System（连线/箭头语义与克制）

- 线宽统一 1.0–1.2pt；颜色 `Line`；箭头 `-|>` 小号（mutation_scale ≤ 12）。
- AND/OR 视觉区分**靠形状+文字双编码**（不靠颜色）：AND 用带"（AND）"标签的方框或拱形符号，
  OR 用"（OR）"标签/月牙形——灰度打印可辨。
- 正交折线优先（elbow routing），减少斜穿；连线不得交叉（交叉→改路由/拆图，VIS 检）。
- 箭头方向唯一语义：因果/传播方向一致（顶→底 或 输入→输出），全论文统一。

## F. Label System（标签可读与不歧义）

- 每节点标签=编号+短名（"E1 EDP磨损内泄"），编号与正文/注册表一致（VIS 关联 D10 数据核对）。
- 标签不换行到不可读；长标签缩写并加图例说明；单位随数值。
- 禁止"仅靠颜色区分类别"（与 A-5 呼应）。

## G. Caption System（双语题注，与文档级 QA 对齐）

- 中文题在图下第一行、英文题第二行（FIG-07/08/09 已保证），编号"图X-Y"与正文引用一致（FIG-12/13）。
- 题注字号 10.5，宋体（与正文表题统一）；模拟/假设口径标签**在题注内可见**（诚信）。
- 题注不与图/正文粘连（GQ-12/13 间距）。

## H. Figure Size System（尺寸/缩放/有效字号闭环）

- 版心宽基准（中飞院 16.5cm 实测）；生成宽 = 目标显示宽 / 缩放，使**有效字号≥9pt**（GQ-09）。
- 宽高比约束：单图 aspect 0.6–2.2（超宽→拆/旋转）；独立图页占用率 ≥55%（GQ-14）。
- 导出：PNG dpi ≥ 220（打印 300dpi 可辨）；SVG/PDF 矢量优先（避免字体/线宽/裁切栅格损失，见 §十三）。

## I. Figure Type System（类型分派，见 03 文档细化）

`figure_style.py` 定义 `FIGURE_TYPES = {fault_tree, flow, tech_route, stat_bar, stat_line,
decision_matrix, architecture, comparison, framework}`，每类型绑定专属规范（结构/色/字/距/层级/标签/题注），
**不允许所有图套同一模板**（任务 §七）。provider 生成时按 type 取规范；QA 按 type 选阈值（VIS-11 类型适配）。

## J. Academic Style Rules（学术克制总则）

- 少即是多：无装饰性图标/背景块/3D/阴影/渐变；数据墨水比（data-ink ratio）最大化。
- 一致性优先于单图炫技：跨图统一（VIS-12）高于单图"更花哨"。
- 一切视觉变换不得改数据语义（§九 Data Integrity 为最高优先，先于美观）。
- 可解释性：任何颜色/线型/形状选择都能回答"为什么"——映射自 SEMANTIC 字典，非随手取色。

## 单一来源与去硬编码（消灭 D3/D4 的实现约束）

新增 `scripts/figure_style.py`（v1.6.5 实现阶段）：导出 `PALETTE / SEMANTIC / FONT / FONTSIZE /
SPACING / LINE / FIGURE_TYPES` 常量与 `contrast_ratio() / grayscale_delta() / ink_ratio()` 纯函数。
figkit / 各 provider / QA **一律 import 此模块**，禁止在图脚本内写死 HEX/字号——
这是"不针对单篇/单例硬编码"（§十五-8/9）的结构保证，也是 VIS-06/12 可机检的前提。
