# 术语对照表（terminology-glossary）

**本卡在 S1/S3/S5/S7 阶段按需加载，确保全文术语一致、工程化表达。**

## 核心术语区分

| 术语 | 推荐用法 | 禁止混用 | 示例 |
|---|---|---|---|
| **故障 (Fault)** | 功能丧失或偏离规定性能的状态 | 与"失效/损伤/缺陷/异常"混用 | "起落架无法放下是故障" |
| **失效 (Failure)** | 部件/系统失去规定功能的事件 | 与"故障"互换（失效侧重事件，故障侧重状态） | "密封件失效导致内漏" |
| **损伤 (Damage)** | 结构材料的物理破坏（裂纹、腐蚀、凹陷） | 与"故障"混用（损伤是物理状态，故障是功能状态） | "机翼蒙皮出现疲劳裂纹损伤" |
| **缺陷 (Defect)** | 制造或使用中产生的不满足要求的瑕疵 | 与"损伤"混用（缺陷可能是先天性的） | "焊接处存在气孔缺陷" |
| **异常 (Abnormality)** | 偏离正常但未达到故障程度的现象 | 直接认定为故障 | "液压压力略低于标准值属异常，需监控" |
| **故障模式 (Failure Mode)** | 功能失效的具体形式 | 与"故障原因/现象"混淆 | "无法锁定"是模式；"锁销断裂"是原因 |
| **故障原因 (Failure Cause)** | 导致故障模式的物理/化学/人为机制 | 只写"磨损"而不说明机制 | "密封件因长期受压产生永久变形" |
| **故障后果 (Failure Effect)** | 故障对上层系统或安全的影响 | 与"局部影响"混为一谈 | 局部：起落架停留在收上位；最终：着陆时机体损伤 |
| **维修 (Maintenance)** | 保持或恢复物品处于能执行规定功能状态的全部技术与管理活动 | 与"修理"互换（维修是总称） | "定期维护属于预防性维修" |
| **维修策略 (Maintenance Strategy)** | 针对特定故障模式选择的维修方式组合 | 与"维修方案/大纲"混用 | "对高风险模式采用视情维修" |
| **维修方案 (Maintenance Program)** | 具体执行的维修任务清单与间隔 | 与"策略"混用（方案是策略的落地） | "每 500 飞行小时检查作动筒密封" |
| **维修大纲 (Maintenance Schedule)** | 基于 MSG-3 等方法制定的全机维修任务框架 | 与"方案"混用（大纲更宏观） | "基于 ATA 章节编排的全机定检大纲" |
| **可靠性 (Reliability)** | 产品在规定条件下和规定时间内完成规定功能的概率 | 与"可靠度/可用度"混用 | "该系统可靠性为 0.95/1000 小时" |
| **可靠度 (Reliability Value)** | 可靠性的数值表达 | 与"可靠性"互换使用而不加区分 | "可靠度 R(t) = e^(-λt)" |
| **可用度 (Availability)** | 产品在任意随机时刻需要时处于可工作状态的概率 | 与"可靠度"混用 | "可用度 A = MTBF / (MTBF + MTTR)" |
| **维修性 (Maintainability)** | 产品在规定时间内按规定的程序和方法进行维修时，保持或恢复到规定状态的能力 | 与"维修"混用 | "该部件维修性好，平均修复时间短" |

## 论文写作常用词规范

| 术语 | 推荐用法 | 禁止写法 |
|---|---|---|
| **结果 (Result)** | 分析/实验的直接产出（数据、图表、排序） | 与"结论"互换 |
| **结论 (Conclusion)** | 基于结果得出的判断或建议 | 直接复述结果而不提炼 |
| **假设 (Assumption)** | 分析中为简化问题而设定的前提条件 | 写成事实；不标注【假设】 |
| **验证 (Verification)** | 通过对比、测试或逻辑推导确认某陈述的正确性 | 与"估计/预测"混用 |
| **分析 (Analysis)** | 对数据进行分解、比较、归因的过程 | 只罗列数据不做解释 |
| **估计 (Estimation)** | 基于有限信息给出的近似值 | 写成精确测量值 |
| **预测 (Prediction)** | 基于模型对未来状态的推断 | 与"估计"互换而不说明时间维度 |

## 量与单位规范

- **压力**：MPa（兆帕），禁止用"公斤力"等非 SI 单位
- **载荷**：kN（千牛），禁止用"吨力"
- **转速**：r/min（转/分）或 %N1（发动机参数）
- **温度**：℃（摄氏度）
- **数值与单位间**：加空格（如"10 MPa"），除非学校模板另有规定

## 句式模板

- **客观口吻**：用"本文/本研究"，不用"我/我们"
- **因果表述**：用"由于…导致…"，不用"因为…所以…"（口语化）
- **结果表明**：仅在有数据支撑时使用；无数据时用"分析显示/推测"
- **首次出现缩写**：给中英全称，如"故障模式与影响分析（Failure Mode and Effects Analysis, FMEA）"
