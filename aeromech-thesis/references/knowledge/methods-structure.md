# 结构分析方法知识卡（methods-structure）

**本卡只在 S3/S5 阶段由 Engineering Agent 加载，面向航空器/机械结构有限元分析论文。**

## 1. 有限元分析标准流程

```
工况定义 → 几何与材料 → 边界条件 → 网格划分 → 网格无关性验证 → 求解 → 结果后处理 → 强度判定 → 结论
```

### 各环节要点
| 环节 | 关键检查项 | 常见错误 |
|---|---|---|
| **工况定义** | 载荷大小/方向/作用点；约束类型（固定/铰支/滑动） | 载荷来源不明；忽略动态载荷系数 |
| **几何与材料** | CAD 模型简化原则；材料参数（E, ν, σ_y）来源 | 保留不必要的细节导致网格过密；材料参数无出处 |
| **边界条件** | 约束是否过定位；接触面定义 | 过约束导致应力奇异；欠约束导致刚体位移 |
| **网格划分** | 单元类型（四面体/六面体）；网格密度梯度 | 关键区域网格过粗；过渡区畸变单元 |
| **网格无关性** | 至少三种网格密度对比，结果变化 <5% | 只做一次网格，声称"已收敛" |
| **求解** | 线性/非线性；静力/动力 | 非线性问题用线性求解器 |
| **结果后处理** | 应力云图、位移云图、安全系数分布 | 只看最大应力点，忽略整体变形模式 |
| **强度判定** | von Mises 应力 vs 屈服强度；安全系数 = σ_y / σ_max | 直接把最大应力等同于失效；忽略疲劳极限 |

## 2. 分析类型与适用场景

| 类型 | 目的 | 输入 | 输出 | 本科可完成度 |
|---|---|---|---|---|
| **静力分析** | 校核结构在静态载荷下的强度与刚度 | 载荷、约束、材料 | 应力、位移、安全系数 | 高 |
| **模态分析** | 识别固有频率与振型，避免共振 | 质量矩阵、刚度矩阵 | 前 N 阶频率、振型 | 高 |
| **疲劳分析** | 评估循环载荷下的寿命 | S-N 曲线、载荷谱 | 损伤累积、预测寿命 | 中（需 S-N 数据） |
| **结构优化** | 在满足强度前提下减重 | 设计变量、目标函数、约束 | 最优几何/拓扑 | 低（需专业软件） |

## 3. 常见错误自查清单

- [ ] **过约束**：在同一自由度上施加多个约束，导致反力异常
- [ ] **边界条件不合理**：如将实际弹性支撑简化为完全固定
- [ ] **应力奇异点**：尖角/点载荷处应力理论无穷大，需圆角或分布载荷处理
- [ ] **只看云图颜色**：不读取具体数值，无法定量判断
- [ ] **没有网格独立性验证**：未证明结果不依赖网格密度
- [ ] **直接把最大应力等同于结构失效**：应比较许用应力或安全系数
- [ ] **材料参数来源不明**：必须标注来自手册/文献/实验，标【待核实】若无出处
- [ ] **载荷来源不明**：必须说明是设计载荷、试验载荷还是估算值

## 4. 重要声明

> **软件输出结果 ≠ 自动等于真实工程结论。**

有限元结果是数值近似，其有效性取决于：
1. 模型是否合理反映物理现实
2. 边界条件是否正确
3. 网格是否足够精细
4. 材料本构是否适用

**Engineering Agent 必须在 `basis-notes.md` 中明确上述四点的依据与局限。**

## 5. 本科可完成的分析层级

| 分析 | 所需软件 | 替代方案 |
|---|---|---|
| 静力分析 | ANSYS Student / Abaqus Edu / SolidWorks Simulation | 手算简支梁/板公式校核关键点 |
| 模态分析 | 同上 | 解析法计算简单结构一阶频率 |
| 疲劳分析 | nCode / fe-safe（商业） | 基于 S-N 曲线的手工 Miner 法则估算 |
| 结构优化 | ANSYS Optimization / Topology Opt. | 参数扫描法手动调整几个关键尺寸 |

**超出本科层级的内容（本卡不提供）**：显式动力学、流固耦合、复合材料分层失效、断裂力学 J 积分。
