# 可靠性分析方法知识卡（methods-reliability）

**本卡只在 S3/S5 阶段由 Engineering Agent 或 Data Agent 加载。**

## 1. 核心指标定义与关系

| 指标 | 定义 | 量纲 | 计算式 | 常见误读 |
|---|---|---|---|---|
| **可靠度 R(t)** | 产品在规定条件下和规定时间内完成规定功能的概率 | 无量纲 (0–1) | R(t) = P(T > t) | 不等于"质量好"，是时间函数 |
| **失效率 λ(t)** | 工作到 t 时刻后单位时间内发生故障的概率 | 1/时间 | λ(t) = f(t)/R(t) | 恒定失效率仅适用于指数分布 |
| **MTBF** | 平均故障间隔时间（可修复产品） | 时间 | MTBF = 总运行时间 / 故障次数 | **MTBF 高 ≠ 安全性高**；只反映频率，不反映后果严重度 |
| **MTTR** | 平均修复时间 | 时间 | MTTR = 总修复时间 / 修复次数 | 不包括等待备件/人员的时间 |
| **可用度 A** | 产品在任意随机时刻需要时处于可工作状态的概率 | 无量纲 (0–1) | A = MTBF / (MTBF + MTTR) | 高可用度可通过缩短 MTTR 实现，不一定提高 MTBF |
| **维修性 M(t)** | 产品在规定时间内按规定的程序和方法进行维修时，保持或恢复到规定状态的概率 | 无量纲 | M(t) = 1 - e^(-μt)，μ=1/MTTR | 与维修策略和备件供应强相关 |

**重要声明**：上述公式基于经典可靠性理论，假设故障独立同分布。实际航空系统中故障往往存在相关性（如共因失效），需结合 FMEA/FTA 综合评估。

## 2. Weibull 分布

### 基本形式
- 累积分布函数：F(t) = 1 - exp[-(t/η)^β]
- 可靠度函数：R(t) = exp[-(t/η)^β]
- **形状参数 β**：决定失效率变化趋势
  - β < 1：早期失效期（失效率递减，如磨合期缺陷）
  - β ≈ 1：偶然失效期（失效率恒定，近似指数分布）
  - β > 1：耗损失效期（失效率递增，如疲劳、磨损）
- **尺度参数 η**：特征寿命（63.2% 的产品在此时间前失效）

### 适用场景与限制
- **适用**：寿命数据服从单调失效率趋势；样本量 ≥10 时参数估计较稳定。
- **小样本限制**：n < 10 时 β 和 η 的置信区间极宽，参数估计不可靠。此时应使用非参数方法（如 Kaplan-Meier）或贝叶斯先验。
- **参数估计不得伪造**：若无真实故障时间数据，不得生成所谓"飞机实际 Weibull 参数"。必须标**【待填】**或**【假设/模拟·仅演示方法】**。

### 常见误读
- [ ] 把 Weibull 拟合结果当作唯一真理（应与其他分布如指数、对数正态比较）
- [ ] 忽略截尾数据（右截尾/左截尾需特殊处理）
- [ ] 用少量故障点强行拟合（应报告置信区间）

## 3. 指标之间的逻辑关系

```
MTBF ↑ → 若 MTTR 不变 → 可用度 A ↑
MTTR ↓ → 若 MTBF 不变 → 可用度 A ↑
R(t) 高 → 不一定 MTBF 高（可能测试时间短）
MTBF 高 → 不一定安全（若单次故障后果灾难性，S=10）
```

**工程判断原则**：可靠性指标必须与 FMEA 中的 Severity 结合使用。高 MTBF 但高 S 的模式仍需优先处理。

## 4. 数据来源与依据纪律

- **真实故障数据**：来自机队维修记录、试验台架、公开事故报告。必须注明来源类别（如"某航空公司 2019–2023 年 A320 起落架维修记录【用户提供·未核实】"）。
- **文献数据**：来自期刊论文、手册、标准。必须标【待核实】直至用户确认出处。
- **模拟数据**：用于方法演示时，必须逐处标**【假设/模拟·仅演示方法】**，且不得进入论文正式结论。
- **禁止**：在没有数据的情况下编造 MTBF/MTTR/Weibull 参数；把教材示例值当作某型飞机实际值引用。

## 5. 本科可完成的分析层级

| 分析类型 | 所需数据 | 工具 | 输出 |
|---|---|---|---|
| 描述统计 | 故障时间列表 | Excel/Python | mean, median, std, histogram |
| 指数分布拟合 | 故障间隔时间 | Python (scipy) | λ, MTBF, R(t) 曲线 |
| Weibull 拟合 | 故障时间 + 截尾信息 | Python (reliability 库) | β, η, R(t) 曲线, 置信区间 |
| 可用度计算 | MTBF, MTTR | 手工/Excel | A 值, 敏感性分析 |
| 简单对比 | 两组故障数据 | t检验/ Mann-Whitney | p值, 差异是否显著 |

**超出本科层级的内容（本卡不提供）**：加速寿命试验设计、竞争风险模型、马尔可夫链建模、蒙特卡洛仿真。
