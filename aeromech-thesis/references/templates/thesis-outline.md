# 模板：论文目录（Thesis Outline）

由 `agents/research.md` 在 S3 产出，落盘 `.aeromech/artifacts/thesis-outline.md`。目录必须依据题目与研究方法裁剪，禁止照抄不变。

## 0. 通用骨架（所有类型）

```markdown
摘要
Abstract
目录
第1章 绪论
第2章 …（按类型选择，见下）
…
第N章 结论与展望
参考文献
致谢
附录（可选：分析表全表、计算书、原始数据说明）
```

## 1. research 型（故障分析 / FMEA / 可靠性 / 案例验证）

```markdown
第1章 绪论
  1.1 研究背景
  1.2 研究意义
  1.3 国内外研究现状
  1.4 研究内容与方法
  1.5 技术路线
第2章 相关理论与方法基础
  2.1 <对象>系统组成与工作原理
  2.2 <主方法，如 FMEA>基本原理与实施流程
  2.3 风险评价指标（如 RPN 计算与分级准则）
第3章 研究对象与系统分析
  3.1 研究对象界定与范围
  3.2 系统结构与功能分析
  3.3 典型故障模式识别
  3.4 故障原因与影响分析
第4章 <主方法>实施与风险分析
  4.1 分析流程与评分规则
  4.2 <对象>故障模式分析表
  4.3 风险排序与关键故障模式确定
第5章 维修策略优化与验证
  5.1 现行维修策略及不足
  5.2 针对性维修策略建议
  5.3 案例或资料对照验证
  5.4 实施条件与局限性
第6章 结论与展望
  6.1 主要结论
  6.2 工程应用价值
  6.3 不足与展望
```

## 2. review 型（技术综述 / 现状综述 / 方法或标准对比）

```markdown
第1章 绪论
  1.1 研究背景与意义
  1.2 综述范围与界定
  1.3 文献来源与检索策略
  1.4 综述框架与技术路线
第2章 <主题>发展脉络与现状
  2.1 发展阶段划分
  2.2 国外研究与应用现状
  2.3 国内研究与应用现状
第3章 关键技术/方法分类分析
  3.1 分类依据
  3.2 各类方法原理与适用条件
  3.3 对比分析（维度：精度、成本、可实施性、数据需求）
第4章 存在的问题与影响因素分析
  4.1 技术层面问题
  4.2 管理/实施层面问题
  4.3 影响因素归纳
第5章 发展趋势与应用建议
  5.1 发展趋势
  5.2 对维修实践的建议
  5.3 应用条件与局限
第6章 结论与展望
```

review 型**不要求实验数据章**；第3–4章的依据全部来自文献登记表，逐条可追溯。

## 3. design 型（结构/工艺设计 + 计算或仿真校核）

```markdown
第1章 绪论
  1.1 研究背景与意义
  1.2 设计要求与指标
  1.3 国内外研究现状
  1.4 设计思路与技术路线
第2章 设计理论与方法基础
  2.1 相关设计准则与标准（编号需可核实，否则标【待核实】）
  2.2 载荷与工况分析
  2.3 材料与工艺选择依据
第3章 方案设计
  3.1 总体方案与构型选择
  3.2 主要参数确定
  3.3 结构/工艺方案说明
第4章 计算与校核
  4.1 计算模型与边界条件
  4.2 静力学/强度校核
  4.3 <模态/疲劳/稳定性>校核（按题目取舍）
  4.4 结果分析与方案修正
第5章 <仿真或工艺实施>验证
  5.1 建模与网格划分
  5.2 结果对比与误差分析
  5.3 工程可制造性/可维修性评估
第6章 结论与展望
```

design 型门禁依据 = 设计参数、计算过程或仿真结果说明，**不要求实验数据**。

## 4. 章级逻辑检查位（每章必须能填写）

| 章 | 为什么做 | 做了什么 | 怎么做 | 得到什么 | 说明什么 |
|---|---|---|---|---|---|
| 第3章 | | | | | |

任一格填不出 → 该章逻辑薄弱，需修订目录或补依据（触发 S7→S3/S4/S5/S6 回退）。

## 5. 图表点位表（S8 轻量版，写作时随章产出）

| 编号 | 类型 | 内容 | 所在章节 | 正文引用位置 | 数据来源 |
|---|---|---|---|---|---|
| 图1 | 技术路线图 | 研究流程 | 1.5 | “如图1所示” | 自绘 |
| 表1 | 故障模式分析表 | ××系统故障模式 | 3.3 | “见表1” | <来源或【待核实】> |

规则：编号全文唯一且连续；每图/表必须在正文被引用；内容与正文一致；不为凑页数添加图表。
